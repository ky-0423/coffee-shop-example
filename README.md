# Your Coffee Shop website

A responsive, no-build website made with plain HTML, CSS, and JavaScript. Open `index.html` in a browser to use it. No install step is needed.

## Personalize the placeholders

- Replace **Your Coffee Shop**, the introduction, address, hours, contact details, and social link in `index.html`.
- Set each drink's `price` in `script.js` to a number (for example `4.50`). Prices are intentionally blank until you supply them; the cart calculates a total after prices are entered.
- To add tea, other drinks, or pastries, add objects to the `products` array in `script.js`. Use category `tea` or `other` and point `image` to a file inside `assets/`.
- Replace the `address` value in the directions click handler in `script.js` with the real shop address. The button will then open Google Maps.
- Replace the email and phone links alongside their placeholder text in `index.html`.
